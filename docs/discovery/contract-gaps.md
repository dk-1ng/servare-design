# Contract gaps

Data or actions the UI needs that `references/ui-contract.md` does not provide. Each entry becomes an issue in `dk-1ng/servare` during D8. Until then the prototype must not use the proposed field; it designs the fallback instead.

| ID  | Found in    | Use case                                                                                                                     | Missing                                                                                                                          | Proposed addition                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Fallback until then                                                                                                                                                                                                                                                                                                                              |
| --- | ----------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| G1  | #5 (J3, J5) | After a download finishes, or later from history, the user wants to open the file or show it in its folder ("where is it?"). | No action to open or reveal a delivered file; neither `DownloadJob` nor `HistoryEntry` exposes a handle to the browser download. | `download/open { jobId }` and `download/show { jobId }`, plus `history/open { entryId }` and `history/show { entryId }` (backed by `downloads.open` / `downloads.show`). Response `null`; fails with `handler-failed` when the file no longer exists. Caveat: Firefox only allows `downloads.open` from a user-input handler, and the gesture is lost across a `runtime.Port` message, so a background-side `open` may be refused. Alternative (preferred for `open`): an optional `downloadId?: number` on `DownloadJob` and `HistoryEntry`, so the extension page calls `downloads.open` / `downloads.show` directly in its click handler. | Show `outputName` in plain words: "Saved in your downloads folder as …", or "Saved where you chose as …" (only when `settings/get` answers; with `saveAs` on, the shown name is the proposed one) when `Settings.saveAs` is on. Mention the subfolder only when `settings/get` answers (M5, #34); never assume the folder is called "Downloads". |
| G2  | #5 (J4, J5) | A failed entry in history should say why it failed, as the queue does.                                                       | `HistoryEntry.status` can be `failed`, but the entry has no error.                                                               | `HistoryEntry.error?: DownloadError` (present when `status` is `failed`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Generic "This download did not finish" with a link to the page (`pageUrl`) to try again.                                                                                                                                                                                                                                                         |
| G3  | #5 (J5)     | Finding one past download in a long history.                                                                                 | `history/list` only accepts `limit`; no offset or query.                                                                         | `history/list { limit?, before?: number /* completedAt cursor */, query?: string }`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Load with a generous `limit` and filter `title`, `outputName` and `pageUrl` in the UI.                                                                                                                                                                                                                                                           |
